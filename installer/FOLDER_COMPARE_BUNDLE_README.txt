Folder Compare Tool Bundle

What this does:
- Compares any two folders without modifying either one.
- Produces an Excel workbook, CSV files, JSON metadata, and a compare log.
- Helps identify files missing from the reference folder, changed after a cutoff date, cleanup review candidates, and ambiguous matches.

How to run:
1) Extract this zip.
2) Double-click Launch-FolderCompareTool.cmd.
3) Select the Primary Folder and Reference Folder.
4) Pick a cutoff date.
5) Click Run Compare.
6) Review the output folder that opens automatically.

Default examples:
- Primary Folder:   P:\1000_Software
- Reference Folder: C:\Users\akiswani\Documents\SoftwareFolderCompare

Important:
- This tool does not delete, move, archive, or modify any files.
- Output is written locally and cannot be placed inside either compared folder.
